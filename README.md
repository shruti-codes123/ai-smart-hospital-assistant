# AI Smart Hospital Assistant with Predictive Healthcare Analytics

An AI-based smart hospital management system designed to provide digital healthcare assistance, patient management, appointment booking, medical report management, disease prediction, and healthcare analytics.

## Features

- Patient Registration and Login
- Patient Profile Management
- Doctor Information
- Appointment Booking
- Medical Report Upload and Management
- AI-based Disease Prediction
- Prediction History
- AI Healthcare Chatbot
- Hospital Analytics Dashboard
- MySQL Database Integration
- Flask Backend
- Machine Learning Model

## Technology Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask
- REST API

### Database
- MySQL

### Machine Learning
- Python
- Scikit-learn
- Random Forest Classifier
